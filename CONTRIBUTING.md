# Contributing to Awesome MCP Trading

Thank you for your interest in contributing to this list! Please take a moment to review these guidelines before submitting a pull request.

## Adding an Entry

To add a new entry to the list, please ensure the following:

### Quality Standards

- The project must have a **README** with clear documentation.
- The project must be **actively maintained** (commits within the last 12 months).
- The project must be **related to MCP and trading** (exchanges, market data, portfolio management, DeFi, or trading tools).
- The project must be **publicly accessible** (open-source or publicly available service).
- The project should provide **real value** to the MCP trading community.

### Entry Format

Each entry should follow this format:

```
- [Name](URL) - Description.
```

Rules:

- **Description** starts with a capital letter and ends with a period.
- **Description** should be concise and clearly describe what the project does (no marketing language).
- **Name** should match the project or repository name.
- **URL** must point to a valid, public repository or website.
- Entries are sorted **alphabetically** within their category.

### Choosing a Category

Place your entry in the most relevant existing category. If no category fits, you may propose a new one in your PR description. New categories should contain at least two entries.

## Pull Request Process

1. **Fork** this repository.
2. **Create a branch** for your addition.
3. **Add your entry** in the correct alphabetical position within the appropriate category.
4. **Fill out the PR template** completely.
5. **Submit your pull request** with a clear title (e.g., "Add ProjectName to Crypto Exchanges").

## Removing Entries

If you notice a project that is no longer maintained, has been archived, or the URL is broken, please open a PR or issue to have it removed.

## Updating Entries

If a project has changed its name, URL, or description, feel free to submit a PR with the updated information.

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](code-of-conduct.md). By participating, you are expected to uphold this code.
